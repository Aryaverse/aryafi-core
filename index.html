Open-source smart contracts for the Canton Network

Settle securities against cash in one step, so neither side pays first.

AryaFi Core is a library of Daml contracts for banks, custodians and dealers. Both sides of a trade are set aside, then swapped together in a single transaction, and each institution only ever sees its own business.

v3.1.0 · Beta · not yet independently audited

bond → One transaction ← cash
Buyer Dealer Bank B $4,975,000

Both move together, or neither moves.

Why it matters

Neither side pays first

The bond and the cash are both locked before anything moves. Settlement swaps them in one transaction; if anything doesn't match, nothing moves at all.

Only the right party can act

The rules live in the contracts. A seller can't take back a bond it has committed, and a borrower can't mark its own loan as repaid.

Each firm sees only its own business

On Canton, a contract is shared only with the institutions named in it. A counterparty never sees your other positions or accounts.

One agreed record

Buyer, seller and settlement agent sign the same instruction, so there is nothing to reconcile between them afterwards.

Who takes part in a trade

Each institution runs its own Canton node and holds only the contracts it is part of.

Seller

Dealer Bank A

Sells the bond and is paid at the moment it is delivered.

Buyer

Dealer Bank B

Pays for the bond and receives it in the same step.

Settlement agent

Settlement Agent

Checks that both sides match the agreed terms, then swaps them. It cannot change the terms.

Custodian

Global Custodian

Keeps the bonds for their owners and co-signs each bond position.

Cash bank

Cash Settlement Bank

Holds the cash as tokenized deposits and co-signs each cash position.

Regulator

Securities Regulator

Receives the trade report, and nothing else.

How far along is it?

Works today

  • Bond-for-cash settlement that moves both sides in one transaction
  • Runs on Canton 3.5, the version the Canton Network TestNet runs
  • 326 automated tests; every change is also tested on a five-institution Canton network
  • ISO 20022 payment and securities messages mapped to ledger requests
  • Cash and bond positions follow the Canton Network token standard: wallets can list and send them, and settlement apps can settle them
  • Delivery versus payment through the token standard, against AryaFi cash or another registry's token

Not yet

  • An independent security audit
  • Institutions on different nodes agreeing a trade step by step (today every signer must be on the same node)
  • Loans, repos and securities lending moving real assets (today they track the agreement only)
  • Settling against Canton Coin itself, which needs a Canton Network (tested so far against Splice's reference token)

    What's in the library

    AryaFi Core is a set of contracts that institutions run on their own Canton nodes. Here is what each area does today, and how mature it is.

    Settlement

    Beta: ready to try

    Moves real assets on the ledger today.

    Cash

    Tokenized deposits at a bank: split, merge, transfer with the receiver's consent, and lock for settlement. Wallets and settlement apps can list, send and settle it through the token standard.

    CashPosition

    Securities

    Bonds and equities kept by a custodian, with the same locking and consent rules, and the same token-standard support.

    SecurityPosition

    Delivery versus payment

    Swaps a locked security for locked cash in one transaction, after checking both against the signed terms. Through the token standard, the cash can be any registry's token.

    DvpInstruction · TokenDvpInstruction

    Financing

    Experimental

    Tracks each agreement and who may change it. Cash and securities do not move on the ledger yet.

    Loans

    Credit facilities. Interest is calculated by the contract from the rate and the date; repayments are confirmed by the lender.

    InstitutionalLoan

    Repos

    Sale and repurchase of securities, from opening leg to closing leg, including rolls and substitution.

    RepoAgreement

    Securities lending

    Stock loans with agreed fees, recalls that stay open until met, and collateral released in proportion to what is returned.

    SecuritiesLendingAgreement

    Margin calls

    The payer submits; the caller confirms receipt. Default can only be declared after the deadline.

    MarginCall

    Pledges and collateral

    Collateral valued at market price minus a haircut, revalued and substituted over the life of the agreement.

    AssetPledge · CollateralPosition

    Funds and escrow

    Fund subscriptions and redemptions, and conditional escrow released on agreed conditions.

    FundSubscription · AssetRedemption · ConditionalEscrow

    Try it: how much collateral does a loan need?

    Collateral counts at its market value minus a haircut. With a margin on top, you need loan × margin ÷ (1 − haircut).

    Illustrative haircuts; each agreement sets its own.

    Compliance

    Experimental

    The rules are evaluated correctly, but are not yet enforced automatically inside transfers and settlements.

    KYC and sanctions

    Checks issued by a KYC provider or sanctions screener, with expiry dates. They hold no personal data.

    KycAttestation · SanctionsAttestation

    Transfer rules

    Lockups, holding periods, whitelists, and Reg D, Reg S and Rule 144A investor categories, reporting every rule that fails.

    TransferRestrictionRule

    Eligibility and limits

    Which assets and counterparties are allowed, and how much of an issue one holder may own.

    EligibilityPolicy · OwnershipRestriction

    Regulatory reports

    Report records for SEC CAT, FINRA TRACE, EMIR and MiFIR, acknowledged or rejected by the regulator.

    RegulatoryReportRecord

    Coming next

    Planned
    • Agreeing trades across nodes. Propose-and-accept steps, so the seller, buyer and agent can each sign from their own node.
    • Settling against Canton Coin. AryaFi's delivery versus payment already settles through the token standard against other registries' tokens. Next, it settles a bond against Canton Coin on a Canton Network.
    • Financing on real assets. Loans, repos and securities lending that lock and move the actual cash and securities.
    • An independent security audit of the finished core.

    Build with AryaFi Core

    Daml SDK 3.5.12 and Canton 3.5. Everything below uses the code in this repository.

    Get started

    # Install the Daml SDK (dpm) and build both packages
curl https://get.digitalasset.com/install/install.sh | sh -s 3.5.12
git clone https://github.com/Aryaverse/aryafi-core.git
cd aryafi-core
dpm build --all

# Run the 326 tests
cd daml/test
dpm test --all

    The GitHub repository is private for now, so cloning needs access from Aryaverse.

    Run it on a network

    • Five institutions on your laptop. deploy/docker starts a Canton 3.5 network with one node per institution: docker compose up -d --build.
    • Canton Network TestNet. deploy/testnet has a smoke test and a runbook for a first run on a TestNet validator.
