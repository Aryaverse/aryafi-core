# Reference Application: Secured Institutional Loan

## Overview
Demonstrates institutional term loan origination, collateral pledge tracking, interest schedule calculation, and principal paydown.

## Workflow
1. **Facility Creation**: Lender and Borrower enter into `InstitutionalLoan`.
2. **Collateral Pledge**: Borrower pledges eligible assets via `AssetPledge`.
3. **Paydown**: Borrower exercises `PayDownPrincipal` until final closure.
